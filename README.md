# 📊 Relatório Financeiro com Foco na Experiência do Usuário

Desafio de Projeto do curso **Power BI Analyst** da [DIO](https://www.dio.me/) — Digital Innovation One.

## 📌 Descrição do Desafio

Modificar o relatório financeiro criativo (o primeiro relatório desenvolvido no curso), aplicando melhorias focadas na **experiência do usuário (UX)**. O objetivo é transformar um relatório funcional em um relatório visualmente agradável, intuitivo e fácil de navegar, sem perder a clareza das informações.

## 🎯 Objetivos do Desafio

O relatório foi remodelado levando em consideração os seguintes princípios de design:

| Princípio | Aplicação no Relatório |
|---|---|
| **Posicionamento** | Organização dos visuais em hierarquia visual, com os KPIs no topo e os detalhamentos abaixo |
| **Contraste** | Uso de cores fortes para destacar informações-chave (lucro, margem) sobre fundo escuro |
| **Proporção áurea** | Distribuição equilibrada dos elementos na página, respeitando proporções harmônicas |
| **Segmentação dos dados** | Slicers de filtro (Ano, Período, Categoria) para o usuário explorar os dados de forma interativa |

> 💡 **Nota do curso:** esses pontos não são regras rígidas. Saber quando quebrá-los traz mais criatividade ao relatório e o torna mais interessante.

## 🛠️ Tecnologias Utilizadas

- **Power BI Desktop**
- **Dataset:** `financials` (amostra da Microsoft) — contém dados de vendas, lucro, segmentos, produtos e períodos

## 📊 Estrutura do Relatório

O relatório é composto por **3 páginas**:

1. **Página 1 — Visão Geral**
   - Cards de KPI: Soma de Profit, Profit 2013, Profit 2014, Margem de Lucro
   - Lucro por Produto (barras horizontais)
   - Participação por Segmento (treemap)
   - Lucro por Trimestre (cascata com total)
   - Tendência de Lucro Acumulado (linha)

2. **Página 2 — Detalhamento de Vendas**
   - Matriz de descrição de vendas
   - Gráficos combinados (colunas + linha) por período

3. **Página 3 — Análises Complementares**
   - Visuais adicionais e análises específicas

## 🧭 O que foi Implementado

- ✅ Botões de **navegabilidade** entre as páginas
- ✅ **Menus de navegação** em cada página
- ✅ Botões com estados de **foco/seleção** destacados
- ✅ Segunda página modificada seguindo o mesmo padrão visual da primeira
- ✅ Estilização consistente dos visuais (cores, fontes, espaçamentos)
- ✅ Gráfico de área ajustado conforme as considerações do curso
- ✅ Matriz de descrição de vendas criada

## 🚀 Como Executar

1. Baixe o arquivo `.pbix` deste repositório
2. Abra no **Power BI Desktop**
3. Explore as páginas usando os botões de navegação e os slicers de filtro
